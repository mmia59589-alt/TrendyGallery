TRENDY GALLERY WEBSITE

1) Open index.html in a browser to preview.
2) Product names/prices and contact number can be changed in index.html.
3) Replace emoji product placeholders with your own product photos before publishing.
4) Free publishing: create a GitHub account, create a public repository named trendy-gallery,
   upload index.html, then enable Settings > Pages > Deploy from a branch > main / root.
   GitHub will provide a free website address.
5) This is a free catalogue website. It does not include online card payment, inventory,
   admin dashboard, or automatic courier integration. Orders are sent to WhatsApp.
